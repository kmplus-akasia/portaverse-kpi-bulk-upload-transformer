1. Ringkasan Eksekutif

KPI Bulk Upload Converter adalah pipeline Python untuk mengubah workbook desain Kamus KPI menjadi workbook resmi yang dapat diunggah ke PMS. Converter membaca workbook sumber atau ZIP batch, menemukan mapping posisi, mengisi template upload 24 kolom, membuat report validasi, lalu menghasilkan manifest untuk menentukan workbook yang siap upload.

Blank identity 0 Tidak ada row tanpa PMID dan PNID pada batch yang diringkas.
Double identity 0 Tidak ada row yang mengisi PMID dan PNID sekaligus.
Prinsip operasional utama: upload hanya workbook yang masuk status READY di upload_manifest.csv, atau workbook yang sudah disalin ke folder upload-ready. Jangan upload report, audit, config, atau file CSV pendukung.

3. Source of Truth dan Artefak Pendukung

Converter harus dijalankan dengan kontrak template dan reference posisi yang benar. Jangan mengubah asumsi kolom atau identity mapping tanpa mengecek source of truth berikut.

Template upload resmi

File template di input/KPI Upload Template.xlsx menjadi bentuk akhir workbook upload. Header yang digunakan berjumlah 24 kolom.

Production position reference

configs/production_position_reference.json menjadi lookup offline untuk PMID, PNID, company, group, dan tipe posisi.

Config posisi

File configs/*.json menentukan sheet, posisi target, scope posisi, PMID atau PNID, dan rule drop khusus.

Manifest validasi

upload_manifest.csv adalah bukti operasional workbook siap upload. Status READY wajib dicek sebelum file diunggah.

4. Pipeline Konversi

Pipeline bekerja dari sumber workbook atau ZIP batch, lalu menulis output per workbook. Setiap output selalu dipasangkan dengan report CSV agar issue dapat ditelusuri tanpa membuka file Excel satu per satu.

5. Spesifikasi Converter Terbaru

5.1 Template dan header upload

Converter menulis ke template upload resmi dengan 24 kolom. Kolom tail yang wajib dipertahankan adalah Ownership Type, Position Nomenklatur ID, dan RKM Code ID. Jangan memakai template lama yang belum memiliki kolom ini.

5.2 Rule identity posisi

Scope posisi Kolom yang diisi Kolom yang dikosongkan Makna operasional
structural Position Master ID (Required) / PMID Position Nomenklatur ID / PNID Row diarahkan ke posisi struktural spesifik.
non_structural Position Nomenklatur ID / PNID Position Master ID (Required) / PMID Backend importer mengekspansi PNID ke daftar PMID terkait.
neglect Tidak dihasilkan sebagai upload row Tidak berlaku Posisi sengaja dikeluarkan dari batch karena belum layak upload.
mapping_conflict Tidak boleh memiliki PMID/PNID final Tidak berlaku Butuh review mapping sebelum dapat dikonversi sebagai upload-ready.
Catatan PNID: dalam workbook dan converter ini, PNID adalah cluster_id dari position nomenclature mapping, bukan ID baris mentah dari tabel mapping.

5.3 Logic parsing dan normalisasi

  • Source sheet dibaca sebagai layout blok dan nilai kosong dapat mewarisi konteks dari baris parent.
  • Nilai placeholder seperti (blank) diperlakukan sebagai kosong.
  • Period dinormalisasi ke enum upload, misalnya Triwulan menjadi TRIWULANAN.
  • Polarity dinormalisasi ke POSITIVE, NEGATIVE, atau NEUTRAL.
  • Cascading dinormalisasi ke DIRECT, INDIRECT, atau DUPLICATE.
  • Ownership dinormalisasi ke SPECIFIC, SHARED, atau COMMON.
  • KAI nature diisi sebagai Routine atau Non Routine berdasarkan nilai sumber atau period.

5.4 Rule drop OUTPUT dan KAI

Converter tidak membawa semua baris sumber ke template upload. Baris OUTPUT atau KAI akan dikeluarkan bila salah satu kondisi berikut terjadi:

  • Kolom comment berisi nilai yang masuk daftar drop, default utamanya Drop.
  • Weight OUTPUT atau KAI kosong.
  • Weight OUTPUT atau KAI bernilai 0 atau setara nol.

5.5 Scope Group 3 dan affiliate

Untuk Group 3, affiliate, atau workbook non-HO, converter harus memakai all-company reference lookup dengan --target-company-id "". Tanpa flag ini, lookup dapat terlalu sempit dan menghasilkan mapping yang tidak sesuai konteks perusahaan.

6. Gating Validasi dan Decision Logic

Gating utama converter ada pada identitas posisi dan validasi workbook akhir. Setiap row upload harus lolos rule identitas sebelum dianggap siap upload.

Gating yang wajib lolos

Gate Kondisi lolos Jika gagal
Header template Header 24 kolom sesuai template upload. Workbook dianggap tidak sesuai kontrak upload.
Report CSV Tidak ada row dengan severity=error. Batch tidak boleh diupload sebelum error diperbaiki.
Identity scope PMID valid untuk structural, PNID valid untuk non-structural. Row ditandai error pada validasi batch.
Blank/double identity blank_identity_rows=0 dan double_identity_rows=0. Status workbook menjadi FAIL.
Expected workbook count Jumlah workbook sesuai parameter --expected-workbooks. Validasi batch memberi error agar folder tidak salah upload.

7. Panduan Penggunaan Converter

7.1 Setup awal

cd /Users/alfredoteja/Documents/portaverse-kpi-bulk-upload-transformer
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt

7.2 Run ZIP batch

Gunakan mode ZIP bila sumber berisi banyak workbook. Converter akan membuat folder output per workbook dan report CSV per workbook. 

python3 scripts/kpi_bulk_transform.py \
  --source "/absolute/path/to/KAMUS KPI GROUP 2.zip" \
  --template "input/KPI Upload Template.xlsx" \
  --mapping "configs/production_position_reference.json" \
  --output-dir "output/group2_conversion_YYYYMMDD_HHMM"

7.3 Run Group 3 atau affiliate

Untuk batch non-HO, kosongkan target company agar lookup membaca seluruh company di reference. 

python3 scripts/kpi_bulk_transform.py \
  --source "/absolute/path/to/KAMUS KPI GROUP 3.zip" \
  --template "input/KPI Upload Template.xlsx" \
  --mapping "configs/production_position_reference.json" \
  --target-company-id "" \
  --output-dir "output/group3_conversion_YYYYMMDD_HHMM"

7.4 Run satu workbook

python3 scripts/kpi_bulk_transform.py \
  --source "/absolute/path/to/source.xlsx" \
  --template "input/KPI Upload Template.xlsx" \
  --config "configs/pre_restructure_positions_rw_reviewed_20260609.json" \
  --mapping "configs/production_position_reference.json" \
  --output "output/single_conversion.xlsx" \
  --report "output/single_conversion.report.csv"

7.5 Build recap workbook

python3 scripts/build_conversion_recap.py \
  --output-dir "output/group2_conversion_YYYYMMDD_HHMM" \
  --config "configs/pre_restructure_positions_rw_reviewed_20260609.json" \
  --reference "configs/production_position_reference.json" \
  --output "output/group2_conversion_recap.xlsx" \
  --report-scope "Group 2"

7.6 Validate batch dan siapkan upload-ready

python3 scripts/validate_kpi_upload_batch.py \
  --output-dir "output/group2_conversion_YYYYMMDD_HHMM" \
  --config "configs/pre_restructure_positions_rw_reviewed_20260609.json" \
  --reference "configs/production_position_reference.json" \
  --expected-workbooks 900 \
  --upload-ready-dir "output/group2_conversion_YYYYMMDD_HHMM/upload-ready" \
  --zip-output "output/group2_conversion_YYYYMMDD_HHMM/upload-ready.zip"

8. Checklist Operasional Sebelum Upload

1. Cek manifest Pastikan semua row di upload_manifest.csv berstatus READY.
2. Cek identity Pastikan blank_identity_rows dan double_identity_rows bernilai 0.
3. Cek report CSV Buka atau grep .report.csv dan pastikan tidak ada severity=error.
4. Gunakan folder upload-ready Upload file dari upload-ready bila folder itu dibuat oleh validator.
5. Jangan upload artefak pendukung Jangan upload .report.csv, recap, discovered config, audit CSV, atau file markdown.
6. Simpan bukti run Simpan path output, manifest, command, dan tanggal run agar batch bisa ditelusuri ulang.
Stop condition: bila ada workbook FAIL, ada error di report, jumlah workbook tidak sesuai ekspektasi, atau ada blank/double identity, jangan upload batch tersebut. Perbaiki config atau mapping dulu, lalu regenerate batch yang terdampak.

9. Troubleshooting Singkat

Gejala Kemungkinan penyebab Tindakan
PNID terlihat seperti PMID Config memakai ID yang salah atau bukan cluster_id. Cek ulang terhadap configs/production_position_reference.json.
Group 3 banyak mapping tidak cocok Lookup masih dibatasi company default. Run ulang dengan --target-company-id "".
Report berisi invalid enum Nilai sumber berada di kolom salah atau memakai istilah non-upload. Cek row sumber dan normalisasi field period, polarity, cascading, ownership, atau KAI nature.
Workbook count tidak sesuai ZIP sumber, filter config, atau expected count tidak sinkron. Bandingkan isi ZIP, discovered config, dan parameter --expected-workbooks.
Row KPI hilang dari output Row kena rule drop karena comment Drop, weight kosong, atau weight 0. Cek report info dan workbook sumber pada row terkait.
